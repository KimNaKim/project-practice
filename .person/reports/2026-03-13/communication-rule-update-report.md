# 통신 및 리뷰 언어 규칙 업데이트 보고서

## 1. 작업 요약
- AI와의 모든 소통 및 코드 리뷰 언어를 **한국어**로 명시하는 규칙을 `.ai/rules/common-rule.md`에 추가했습니다.

## 2. 변경 사항
- **파일명**: `.ai/rules/common-rule.md`
- **추가 섹션**: `## Communication (언어 규칙)`
- **세부 내용**:
    - 모든 세션 시작, 답변, 코드 설명 및 리뷰는 한국어를 원칙으로 한다.
    - 기술 용어는 영어를 사용할 수 있으나 설명은 한국어로 제공한다.

## 3. 검증 결과
- 파일 수정이 성공적으로 이루어졌음을 확인했습니다.
- 규칙 추가 이후 모든 응답을 한국어로 진행하고 있습니다.

## 4. 비유로 설명하기
- 마치 **"글로벌 회의실에서 공식 공용어를 한국어로 지정한 것"**과 같습니다. 이제 모든 안내문, 회의록, 대화는 한국어로 작성되며, 전문 용어가 나오더라도 한국어로 친절하게 해설하는 가이드라인이 마련되었습니다.
